## Folders and files this applies to (original work)

These paths include original work for this game (and, in some cases, third-party files credited below):

- `assets/audio/` — original music and many original sound effects
- `assets/char/` — original space suit, helmet, backpacks, bedroll, and straw kasa, built for this game
- `assets/lightmap/` — lightmaps baked for this game
- `assets/models/` — models made or reworked for this game
- `assets/pbr/` — material textures used in the game (many are third-party; see below)
- `assets/sky/` — sky images used in the game (third-party sources; see below)
- `assets/space/` — space and planet maps used in the game (third-party sources; see below)
- `assets/terrain/` — terrain data prepared for this game
- `assets/nature-full.glb`, `assets/nature-full.k.glb`, `assets/nature-lite.glb`, `assets/nature-lite.k.glb` — packed garden and nature scenes
- `assets/ktx2.json` — index of compressed textures
- `icons/` and `src-tauri/icons/` — app icons and the Zen Multiverse mark
